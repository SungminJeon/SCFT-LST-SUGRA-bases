# SUGRA Catalog — Usage Guide

This folder bundles 6D F-theory SUGRA bases generated by the
`gen_sugra_*` pipeline. Each tensor number `T_H` has its own catalog;
the catalogs for all tensor numbers are pre-filtered (sugra entries
only) and grouped into per-decade `.zip` archives so you only pay
disk/I-O for the slice you actually want to analyze.

The query interface is a Python library that reads the catalog zips
directly — no extraction step required.

---

## Folder layout

```
<bundle-root>/
├── README.md                 ← this file
├── sugra_catalog.py          ← Python library (parser + queries)
├── example_for_hamada.py     ← Python usage example
│
└── catalogs/                 ← pre-built, sugra-only catalogs
    ├── catalogs_T1-10.zip       T_H =   2 .. 10   (≈ 3.0 M entries)
    ├── catalogs_T11-20.zip      T_H =  11 .. 20
    ├── catalogs_T21-30.zip      T_H =  21 .. 30
    ├── ...
    └── catalogs_T141-150.zip    T_H = 145
```

The bundle is self-contained — drop it anywhere and run the example
from its root. The library reads directly from the catalog zip, so
no extraction step is required.

## One-shot run

From the repository root (the folder containing this README):

```bash
python3 example_for_hamada.py
```

The example loads `T_H = 2..4` from `catalogs/catalogs_T1-10.zip`
(~10 s on 8 cores), prints field summaries, runs every query
pattern, and tabulates a sample result.

The catalog path is resolved relative to the script's own location,
so you can move the bundle anywhere and the example keeps working.

---

## Interactive use (Jupyter / IPython)

```python
from sugra_catalog import (
    load_catalog, pick_bases, entry_t_min,
    find_by_combo, find_containing_tag,
    show_entry, show_if, table_form,
)

# Path is relative to your current working directory.
entries = load_catalog(
    "catalogs/catalogs_T1-10.zip",
    t_h_range=(2, 4),       # widen later: (2, 10) for full decade
)

hits = pick_bases(entries, t_h=3, externals=["e6", "su3"])
print(table_form(hits))
print(show_entry(hits[0]))
```

Loading is parallel (`workers=8` by default). Passing
`workers=1` is useful when debugging.

## `Entry` fields

Each parsed entry is a `sugra_catalog.Entry` dataclass:

| field | meaning |
|-----------------|---------|
| `id`            | catalog-local identifier |
| `combo`         | `"+"`-joined external tag string, e.g. `"e6+su3"` |
| `externals`     | list of dicts: `curveIdx`, `specId`, `tag`, `extSI`, `targetSI`, `intNum`, `isHat1` |
| `catalog_id`    | sub-catalog numeric id |
| `catalog_type`  | human-readable LST label (`DM:A(3)`, `NN`, …) |
| `base_t`        | T_H (tensor count of the underlying LST) |
| `T`             | sig_neg of the extended base (= T_H + externals) |
| `Hc`, `V`, `Hn` | hypers (charged), vectors, hypers (neutral) |
| `det`           | determinant of IF |
| `sig_pos` / `sig_neg` / `sig_zero` | IF signature |
| `IF`            | `numpy.ndarray` (intersection-form matrix) |
| `remaining`     | residue curve list |
| `source`        | originating `<zip>!<file>` path |

`entry_t_min(entry)` returns T_min (`None` if the IF is unimodular).

## Query cheat-sheet

```python
# All bases with T_H = 3
[e for e in entries if e.base_t == 3]

# All bases with T_min = 7
[e for e in entries if entry_t_min(e) == 7]

# Exact external multiset (order-independent)
pick_bases(entries, externals=["e6", "su3"])

# Combined filter
pick_bases(entries, t_h=3, t_min_val=6, externals=["e6", "su3"])

# Exact combo string (order-sensitive, fastest)
find_by_combo(entries, "su2+su2+su3")

# Contains at least one e8 external
find_containing_tag(entries, "e8")

# Pretty-print a result list
print(table_form(hits))
print(show_entry(hits[0]))
print(show_if(hits[0]))     # the IF matrix
```

## Switching to another decade

Just change the catalog path. No extraction is needed.

```python
load_catalog("catalogs/catalogs_T11-20.zip", t_h_range=(11, 15))
load_catalog("catalogs/catalogs_T21-30.zip")          # all of it
```

If you would rather work from extracted directories, unzip once:

```bash
cd catalogs
unzip catalogs_T11-20.zip -d T11-20
```

and then pass the directory path to `load_catalog(...)`.

## External tag reference

`pick_bases(externals=[...])`, `find_by_combo("…+…")`, and
`find_containing_tag("…")`. The same tag vocabulary is used in every
decade.

## Catalog filtering rules

The bundled `catalogs_T<lo>-<hi>.zip` archives include **sugra entries
only**. Specifically, for each tensor number `n` in the range we keep
every `.cat` file under

    T_<n>_<n>_su2/cat_phase1_nhc_merged_<sfx>
    T_<n>_<n>_su2/cat_nhc_ext_t<sfx>
    T_<n>_<n>_su2/cat_1ext_nosu2_<sfx>
    T_<n>_<n>_su2/cat_nhc_ext_nhc_ext_unified_<sfx>_r{2..9}{s,ns}ext

and drop every directory whose name ends in `_nonsugra`. Source code,
shell scripts, and `analysis/` files from the original pipeline are
not bundled. Everything inside the zip is therefore safe to feed
straight to `load_catalog`.

## Performance notes

| operation                                | wall time |
|------------------------------------------|----------:|
| load full T1-10 (3.0 M entries, 8 cores) |    ~85 s  |
| load T_H = 2..4 slice (≈1.5 M entries)   |    ~40 s  |
| `pick_bases(...)` on 3 M entries          |   < 1 s  |
| `entry_t_min(...)` for one entry          |   ~0.1 ms (numpy dets) |

Loading scales near-linearly in `T_H_RANGE` width. Once `entries`
is in memory, all subsequent queries are essentially instant.
